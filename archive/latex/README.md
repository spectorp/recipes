# Archived LaTeX cookbook

Historical source for the recipes that lived in this repo before the JSON +
GitHub Pages site. **Not** the live cookbook — that is `data/recipes/*.json`.

| File | Role |
| --- | --- |
| `perry_recipes.tex` | Full LaTeX source |
| `perry_recipes.pdf` | Last compiled PDF |
| `sous_vide_plot.jpg` | Figure used by the TeX |
| `compile_recipes.sh` | Rebuild the PDF (`pdflatex` twice) |

To recompile:

```bash
./compile_recipes.sh
```

(from this directory, or from anywhere — the script `cd`s to its own folder).
